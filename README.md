# EraForge

EraForge — це стратегія-пісочниця, натхненна Sid Meier’s Civilization, де гравець керує цивілізацією, будує міста, досліджує технології, створює армію та взаємодіє з процедурно згенерованою картою.

## 🛠️ Як зібрати і запустити

### g++ (Linux / macOS / MinGW)
```bash
g++ -std=c++17 main.cpp -o EraForge && ./EraForge
```

Просто натисни Run

## 🎮 Що вміє програма
- Будівництво міст
- Будівництво будівель
- Видобуток ресурсів
- Створення юнітів
- Переміщення юнітів
- Дослідження будівель і юнітів
- Поступове відкриття карти
- Процедурна генерація світу

## 🧱 Структура класів
| Класс | Опис |
|-------|------|
| Game | Основна логіка гри |
| Civilization | Ресурси та прогрес гравця |
| Tile | Одна клітинка карти |
| Unit | Юніти та їх логіка |
| Citystate | Города-держави |
| City | Місто та його логіка |
| Building | Будинки та їх логіка |
